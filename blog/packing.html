While working on tests for the sparkle library, I stumbled on the excellent Erich Friedman's packing center. Since the 1990s, Erich has been maintaining a database of the best known polygon packings, showcasing side by side beautiful and cursed configurations. After a few tests with a gradient-free approach, I decided to write polypack, a differentiable polygon packing library based on JAX. The core of the library relies on a differentiable version of the separation axis theorem, which allows to take the gradient of polygon overlaps. To make it efficient and reliable, it required multiple numerical ingredients, including a relaxed augmented Lagrangian approach, a recursive multistart algorithm, and a symmetry reduction technique.

Detailed description in an upcoming paper

The landscape of the cost function is highly rugged and non-convex, riddled with deep local minima. For identical polygons, it presents an exceptionnaly high number of symmetries, in particular (but not only) permutation symmetries, which grow with the factorial of the number of polygons. As an example, the problem of packing 9 identical triangles in a square requires 28 degrees of freedom, but has approximately 57 billion symmetric subspaces.
